# ATIVIDADE 6 — O shell como JCL moderno

# O slide da genealogia mostrou que o JCL usava comandos como
# // ASSIGN SYS004,TAPE para associar um job a um dispositivo.
# No shell moderno, qual mecanismo cumpre papel equivalente?

Resposta:

No shell moderno, o mecanismo equivalente ao JCL são os comandos do terminal e o redirecionamento de arquivos e dispositivos. O shell permite executar programas, organizar tarefas e controlar entrada e saída de dados de forma semelhante ao que o JCL fazia nos sistemas antigos.

# ATIVIDADE 7 — Make

# 1. O monitor histórico verificava a conclusão de cada job antes
#    de despachar o próximo. No make, qual mecanismo cumpre esse
#    papel? Como o make sabe que não precisa recompilar um arquivo
#    que não mudou?

Resposta 1:
O make utiliza dependências e comparação de datas de modificação dos arquivos. Ele verifica se algum arquivo-fonte foi alterado depois do executável ou arquivo objeto. Se nada mudou, ele entende que não é necessário recompilar.

# 2. O monitor unificava "supervisor, carregador e rotinas de I/O
#    sob uma interface textual". O que o Makefile unifica no fluxo
#    de desenvolvimento moderno?

Resposta 2:
O Makefile unifica o processo de compilação, montagem, ligação e automação de comandos do projeto. Ele organiza todas as etapas do desenvolvimento em um único fluxo automatizado.
